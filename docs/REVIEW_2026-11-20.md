# Agent-Tool 程式碼審查（2026-11-20）

[English](REVIEW_2026-11-20.en.md)

本次涵蓋三項工具的 Python、JavaScript、Windows PowerShell 與啟動腳本、繁中翻譯引擎、文件和 CI。使用合成測試資料審查；**未在實際 Windows 桌面登入或啟動官方應用程式**。

| 問題 | 等級 | 結論 |
|---|---|---|
| Codex 的天數篩選可能退回範圍外的舊對話 | 中 | 已修正，不再擴大查詢範圍 |
| Antigravity protobuf 的固定長度資料截斷時未拒絕 | 中 | 已修正並新增負面測試 |
| 啟動紀錄寫入視窗標題和 URL | 中 | 已移除敏感標題、網址與部分安裝路徑資訊 |
| 缺失額度、模型或方案時被當成有效的 0%／GPT／Plus | 中 | 已改成未知值或不顯示，避免製造假數據 |
| 額度失敗重試可能堆積計時器，以及英文 HUD 的參數遮蔽 | 中 | 已修復並重新跑 CI |
| SQLite 路徑含井字號時可能無法讀取 | 中 | 已改為安全 URI 跳脫 |
| Codex 舊 rollout 檔案因 `mtime` 變動覆蓋新額度，或未執行 CLI 時未同步視窗即時額度 | 中 | 已改用事件 ISO 時間戳與過期重置判斷，並在 HUD 直接讀取 ChatGPT 視窗即時 React Fiber 額度狀態 |
| Windows `.vbs` UTF-8 註解在 CP950 下吞行，以及 `fs.existsSync` 無法識別 Store AppExecutionAlias | 中 | 已改為純 ASCII CRLF `.vbs` 與 `fs.lstatSync` 偵測，並於 Windows 10 真機實測通過 |
| 翻譯字典先覆寫再驗證 | 中 | 已改為先驗證、後替換，新增失敗回滾測試 |
| 翻譯預設語言指向不存在的 zh-CN，extra 字典誤列為語言 | 中 | 已修正 |
| Codex 上下文分類含估算值 | 中，既有限制 | 保留實測／推估標示，不宣稱所有分類都是精確 Token |
| Codex 統計最多掃描期間內最近 40 筆對話 | 中，待改善 | UI 和文件揭露上限，未宣稱完整歷史統計 |
| 本機 CDP 連線沒有對同機行程的驗證 | 高，架構殘餘風險 | 保留 loopback 限制與目標篩選，不能宣稱完全安全 |
| Windows 行程關閉與非公開桌面 RPC 的相容性 | 中，待實機驗收 | 繼續由 Issue #3 追蹤，正式 Stable 暫緩 |

## 英文版

已新增兩套 HUD 的英文顯示、英文 Windows 捷徑、終端機「--lang en」、英文 HTML 報表、README、安全政策、貢獻指南、測試說明與英文 Issue 範本。繁中仍為預設；Antigravity 英文模式保留官方原生英文，不注入繁中翻譯。HUD 使用相同 JSON 欄位，避免兩種語言的資料契約分歧。

## 驗證與限制

GitHub Actions 於 Linux、Windows 測試語法、合成統計、雙語 HUD、SQLite 日期範圍、截斷 protobuf、字典合併與英文字元跳脫。Windows Runner 對安全關閉腳本**只做語法解析，不實際結束應用程式**。

完整證據請見 [PR #4](https://github.com/waydefu/Agent-Tool/pull/4)。正式發布仍需 [Issue #3](https://github.com/waydefu/Agent-Tool/issues/3) 所列 Windows 真機驗收。
