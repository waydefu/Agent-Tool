# Tool code review — 2026-11-20

Scope: three tools in `antigravity-zh-tw/`, `agy-cache-watch/`, and `codex-cache-watch/`. Static review of source and synthetic CI checks; **no Windows desktop app has been operated or tested manually**.

| Finding | Severity | Decision |
|---|---|---|
| Codex date filtering could silently include older threads when fewer than 25 threads matched `--days` | Medium | Remove the fallback to unfiltered rows; maintain the requested date constraint |
| Antigravity protobuf decoder skipped past short fixed-width fields instead of rejecting them | Medium | Reject truncated wire types 1 and 5; add negative fixtures |
| Launcher log files stored CDP window titles and URLs that might identify conversations | Medium | Stop logging private window titles or page URLs |
| Dashboard translations were unavailable to English speakers | Medium | Add English HUD mode and English documentation while keeping zh-TW as default |
| Codex classification estimates may look precise next to measured token counts | Medium (existing limitation) | Keep source/estimate labels and document limits; do not market as exact |
| Local CDP ports have no authentication for other processes on the same host | High (residual architectural risk) | Keep loopback-only binding and strict target filters; disclose risk, require manual tests |
| Desktop version detection, app restart, PowerShell process ancestry and quota RPC rely on third-party internals | Medium (open) | Require a Windows desktop acceptance test before any stable release |
| Codex statistics are based on the 40 most recently updated threads | Medium (open) | Disclose bounded coverage in UI and docs rather than claiming complete totals; an incremental full-history aggregator is future work |
| Missing local quota percentages and model/plan metadata were presented as valid zero/Plus/GPT defaults | Medium | Reject unknown quota percentages; use `unknown` for missing model/plan metadata |
| Codex rollout file `mtime` could invert quota chronology, and in-app quota changes were not reflected until a local CLI turn ran | Medium | Order rollout quota by event ISO timestamp / `resets_at`, reset expired windows, and read live in-app React Fiber quota directly in `codex-cache-watch/hud.js` |
| Windows `.vbs` UTF-8 comments broke under CP950 and `fs.existsSync` failed on 0-byte Windows Store `AppExecutionAlias` | Medium | Convert `.vbs` launchers to pure ASCII CRLF and use `fs.lstatSync` for alias detection; verified on Windows 10 desktop |

## Review boundaries

Checking source code and passing Linux/Windows hosted-runner tests do **not** establish runtime safety for installed Electron apps, Windows process trees or real user sessions. No claims of external security certification or full compatibility are made. The project intentionally does not publish a stable release until the acceptance gate is met.
